Computer Basics
Study notes | Five essential computer components
1. The processor (CPU)
The central processing unit, or CPU, executes program instructions. It performs calculations and
coordinates many activities inside a computer. For example, the CPU follows instructions when a
calculator program adds two numbers. The CPU processes information; it is not the main place
where personal files are stored.
2. Working memory (RAM)
Random access memory, or RAM, temporarily holds data and programs that are currently in use.
RAM is volatile: its contents are lost when power is switched off. Opening a program normally places
some of its instructions and data into RAM so the CPU can use them.
3. Long-term storage
Storage keeps files and programs for later use. A solid-state drive (SSD) is one example of a
storage device. Unlike RAM, an SSD retains saved data when power is switched off. Saving a
document writes its contents to storage. Unsaved changes held only in RAM can be lost if power
fails.
4. Input devices
An input device sends data or commands into a computer. A keyboard is used to enter text. A
mouse is used to point, select, and click. A microphone captures sound as input. These devices
allow a user to provide information for the computer to process.
5. Output devices
An output device presents information from a computer to a user. A monitor displays text and
images. Speakers produce sound, and a printer produces a paper copy. Input devices send
information into the computer, while output devices present the results.
